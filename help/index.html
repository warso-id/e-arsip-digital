Pertanyaan Umum (FAQ)

Bagaimana cara membuat surat keluar baru?

Untuk membuat surat keluar baru:

  1. Klik menu Surat Keluar di sidebar
  2. Klik tombol Buat Surat Baru
  3. Ikuti wizard 3 langkah: Informasi Surat, Penerima & Lampiran, Tanda Tangan & Review
  4. Klik Kirim Surat untuk mengirim, atau Simpan Draft untuk menyimpan sementara
Bagaimana cara verifikasi surat dengan QR Code?

Untuk verifikasi surat:

  1. Buka halaman Verifikasi QR Code dari menu Surat Keluar
  2. Scan QR Code pada surat menggunakan kamera, atau upload gambar QR Code
  3. Sistem akan menampilkan informasi keaslian surat

Anda juga dapat memverifikasi melalui URL yang tertera di bawah QR Code.

Bagaimana cara reset password?

Untuk mereset password:

  1. Buka halaman Profile
  2. Pilih tab Keamanan
  3. Masukkan password lama dan password baru
  4. Klik Ubah Password

Jika Anda lupa password, hubungi administrator untuk bantuan reset.

Bagaimana format penomoran surat?

Format penomoran surat standar:

[KODE_UNIT]/[NOMOR]/[KODE_KLASIFIKASI]/[BULAN_ROMawi]/[TAHUN]

Contoh: 123/UN.01/F/XI/2026

Konfigurasi penomoran dapat diubah di halaman Pengaturan > Penomoran.

Bagaimana cara backup data?

Untuk melakukan backup:

  1. Buka Pengaturan > Backup & Restore
  2. Pilih tipe backup (Full/Surat/Users/Settings)
  3. Klik Buat Backup
  4. Download file backup untuk disimpan secara lokal

Anda juga dapat mengatur jadwal backup otomatis (harian/mingguan/bulanan).
